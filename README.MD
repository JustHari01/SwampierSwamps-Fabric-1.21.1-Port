# Swampier Swamps — unofficial Fabric 1.21.1 port

This community port brings Andrew0030's Swampier Swamps to Fabric for Minecraft 1.21.1. It is based on upstream revision `4dd1d145818b6b5b52464607812a5dcfa8534d2c` from the `1.20.4-Fabric` branch. This is an unofficial release and is not affiliated with or endorsed by Andrew0030.

## Features

The port carries over Swampier Swamps' swamp-focused content, including frog variants and frog lights, lily pads, cattails and swamp vines, swamp gas and gas lamps, decaying kelp and fertile farmland, swamp villages, dragonflies, the bald cypress, and other swamp decorations. Existing configuration and gameplay behavior are retained where the 1.21.1 APIs allow them.

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.15.0 or newer
- Fabric API
- Cloth Config 15.0.140 or newer
- Java 21 or newer
